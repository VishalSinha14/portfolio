## Browser Compatibility

- Chrome (recommended)
- Firefox
- Safari
- Edge
- Opera

**Note**: WebGL support is required for 3D animations. Most modern browsers support WebGL by default.

## Customization

### Personal Information
Edit the following sections in `index.html`:
- Update name, title, and description in the hero section
- Modify the about section with your personal information
- Replace project information with your own projects
- Update contact information and links

### Styling
Customize colors and design in `style.css`:
- Change the primary color scheme (currently cyan/blue)
- Modify gradients and animations
- Adjust responsive breakpoints

### 3D Effects
Modify Three.js animations in `script.js`:
- Change star colors and movement patterns
- Adjust floating shapes and their properties
- Modify particle effects and camera movement

## Performance Tips

1. The 3D animations may impact performance on older devices
2. Consider reducing the number of stars (currently 6000) for better performance
3. Test on various devices to ensure smooth experience
